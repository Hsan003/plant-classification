🚀 DÉMARRAGE RAPIDE
════════════════════════════════════════════════════════════════════════════════

1. Vérifier la cohérence:
   $ python verify_project.py

2. Entraîner le modèle (ResNet50):
   $ python 02_model_training.py
   Temps: 5-10 min (CPU) / 1-2 min (GPU)

3. Évaluer les performances:
   $ python 03_evaluation.py
   Génère: Confusion matrix, métriques, analyse d'erreurs

4. Lancer l'interface web:
   $ streamlit run 04_app_streamlit.py
   Ouvre: http://localhost:8501


📈 ARCHITECTURE DU MODÈLE
════════════════════════════════════════════════════════════════════════════════

Input (224×224×3)
    ↓
ResNet50 (ImageNet pré-entraîné)
├─ 25.6M paramètres
├─ Phase 1: backbone gelé (10 epochs, LR=1e-3)
├─ Phase 2: fine-tuning complet (10 epochs, LR=1e-5)
    ↓
Classification Head
├─ Dense(512) + BatchNorm + ReLU
├─ Dropout(0.4)
├─ Dense(256) + BatchNorm + ReLU
├─ Dropout(0.3)
├─ Dense(38) + Softmax
    ↓
Output: 38 probabilités (classes)
